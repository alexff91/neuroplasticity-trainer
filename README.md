# NeuroLearn - Adaptive Learning Platform

An intelligent learning platform built with React that uses neuroscience-backed techniques to optimize your learning experience.

## Features

### Spaced Repetition Flashcards (SM-2 Algorithm)
- Scientifically proven SuperMemo 2 algorithm for optimal review scheduling
- Automatic adjustment of review intervals based on your performance
- Visual indicators for card difficulty and retention rates

### Skill Tree Progression
- Interactive D3.js visualization of your learning journey
- Skill dependencies and unlock progression
- XP-based advancement system

### Interleaved Practice
- AI-powered session composition for better retention
- Mixed topic practice proven to enhance long-term learning
- Category-based filtering and difficulty balancing

### Cognitive Load Monitoring
- Real-time tracking of mental fatigue
- Smart break suggestions based on session performance
- Response time analysis and accuracy trends

### Learning Analytics Dashboard
- Comprehensive charts showing your progress
- Retention rate tracking and forecasting
- Category distribution and study patterns

### Pomodoro Timer
- Customizable focus and break durations
- Brain-break suggestions with activities
- Session tracking and statistics

### Gamification System
- XP rewards for correct answers and streaks
- Level progression with rank titles
- Achievement badges for milestones

## Tech Stack

- **React 19** - UI framework
- **Vite** - Build tool and dev server
- **Tailwind CSS 4** - Styling
- **D3.js** - Skill tree visualization
- **Recharts** - Analytics charts
- **React Router** - Navigation
- **Lucide React** - Icons
- **localStorage** - Data persistence

## Learning Science

NeuroLearn is built on established learning science principles:

- **Spaced Repetition**: Reviews are scheduled at increasing intervals to optimize long-term retention
- **Active Recall**: Testing yourself strengthens memory more than passive review
- **Interleaving**: Mixing different topics during practice improves learning transfer
- **Cognitive Load Management**: Taking breaks at the right time prevents mental fatigue
- **Gamification**: Progress tracking and rewards increase motivation and engagement
